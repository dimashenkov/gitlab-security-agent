The order is part of the claim. preflight_output_dir sits above the skip and above every purchase: the directory this run reads from and writes to is checked before anything is bought. The prompt guard compares the prompt files' bytes against a baseline revision, so an edit that only exists in the checkout is caught too — and the skip label does not waive it. And suppression runs before verification: only findings that can still reach the gate are verified, and an accepted risk is recorded as not verified rather than as confirmed.

Three hallucination layers, not one. report_finding rejects a finding whose evidence does not exist verbatim in the file — before it becomes a finding. The other two are adversarial: the finding is handed back with a mandate to refute it. That is why unclear is a real verdict — a steady “cannot tell” costs less than a different guess every run.
